# Weather App 🌤️

A mobile-friendly **React Native weather app** that shows **current weather** and a **7-day forecast** for any city worldwide. Built with **Expo**, **React Navigation**, and the **Open-Meteo API**.

---

## Features

- 🌞 **Current Weather:** Temperature, weather condition, sunrise/sunset, wind speed.
- 📅 **7-Day Forecasts:** Tap the temperature to view a detailed weekly forecast.
- 🔍 **City Search:** Find weather for any city in the world.
- 🕒 **Live Clock:** Updates every second.
- 🌆 **Automatic Location:** Uses device GPS to show local weather.

---

## Tech Stack

- React Native & Expo
- React Navigation
- Open-Meteo API & OpenStreetMap Nominatim API
- Custom reusable components
